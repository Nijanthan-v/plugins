description: Audit workspace web files for SEO, WCAG accessibility, visual design quality, and code performance.
---

Perform a thorough web audit following the `audit-web-app` skill:
1. Scan HTML files for `<title>`, `<meta name="description">`, semantic elements, and unique IDs.
2. Inspect accessibility compliance (`alt` tags, `aria-label`s, focus indicators, color contrast).
3. Evaluate CSS styles for design system usage, micro-animations, and responsive breakpoints.
4. Review JavaScript logic for error handling, unhandled promises, and memory leaks.
5. Provide a summary report and propose exact code fixes.
